# Contributing

Small, complete improvements are welcome. Open an issue with the workflow you
want to improve, the expected result and a reproducible example using synthetic
data. Do not include customer information or access credentials.

Read AGENTS.md, create a branch, implement one useful change and run the checks
listed there. Include a test that fails before your fix when applicable. A pull
request should explain the problem, the result and the checks run.

Contributions are licensed under the repository's MIT license. AI-assisted
contributions follow the same quality, attribution and privacy requirements.
