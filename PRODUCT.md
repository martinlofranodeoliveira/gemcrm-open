# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Implementation explicitly delegated by the user after confirming this CRM scope.
Django, server-rendered HTML and SQLite provide a small self-hosted baseline.

## Users

Confirmed initial audience: individuals and small businesses following contacts,
sales opportunities and next actions. The owner has left the specific business
vertical open; no industry-specific workflows are claimed.

## Product Purpose

An independent, useful open-source CRM anyone can download, inspect and run.
Success means completing daily contact and opportunity management with clear
ownership and reliable data persistence.

## Operating Context

The first version is a Portuguese-language self-hosted web application. Each
account has its own companies, contacts, deals and tasks. No private GemCRM
project code, customer data or configuration is an input to this project.

## Capabilities and Constraints

Contacts, companies, sales stages, follow-up tasks, search, dashboard and contact
CSV export and reviewed, transactional contact CSV import form the current scope.
MIT-licensed code; no proprietary services are required. This is an early version, not a claim of production readiness.

## Evidence on Hand

New implementation and synthetic examples only. No customers, testimonials,
existing integrations or performance claims have been supplied.

## Product Principles

- Complete useful workflows before expanding scope.
- Isolate each user's records on every operation.
- Keep installation and maintenance understandable.
- Publish meaningful tested changes, never activity for its own sake.

## Accessibility & Inclusion

Keyboard-accessible controls, visible focus, semantic forms and responsive
layouts are implementation requirements for the initial version.
