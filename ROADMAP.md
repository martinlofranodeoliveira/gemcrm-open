# Roadmap

The first version covers contacts, companies, a sales pipeline and follow-up
tasks for an individual user. Further work should solve observable problems.

## Next useful improvements

- Contact import with a preview, row-level validation and duplicate detection.
- Task filters for overdue, today, upcoming and completed work.
- Search that preserves filters while moving through paginated lists.
- Activity history on a contact and its linked opportunities.
- Pipeline reports by date range, with accessible tables and CSV export.
- Database backup and restore documentation, tested using synthetic data.
- Accessibility regression checks for the complete keyboard workflow.

## Contribution requirements

Describe the user problem and acceptance criteria before implementation. Include
regression tests for data isolation and validation, and update setup instructions
when behavior changes. Automation may help implement these tasks, but a public
commit is earned by a working change, never by a schedule.
